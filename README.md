# Better Cricut Editor

Better Cricut Editor is a browser-based A4 design workspace for preparing Cricut-ready PNG, SVG, and PDF exports.

## Current release

Version 33 adds Supabase-backed project saving, a My Projects library, and an account panel with the signed-in email, saved-project count, and sign-out action.

## Deployment

The application is built with `npm run build` and deployed to Cloudflare Workers with `npm run deploy`.
